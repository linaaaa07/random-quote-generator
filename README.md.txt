# Random Quote Generator

**Автор:** Васильева Алина

## Описание

Random Quote Generator — это десктопное приложение с графическим интерфейсом (GUI) на Python, которое позволяет:

- Генерировать случайные цитаты из предустановленного списка
- Фильтровать цитаты по автору и теме
- Сохранять историю всех сгенерированных цитат в JSON-файл
- Добавлять новые цитаты в коллекцию
- Очищать историю

## Требования

- Python 3.6 или выше
- Стандартные библиотеки (tkinter, random, json, os, datetime)
